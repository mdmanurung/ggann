# Security policy

## Supported versions

Security fixes are applied to the latest released minor version of ggann.
Pre-release and development checkouts are supported on a best-effort basis.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security advisory interface for
[`mdmanurung/ggann`](https://github.com/mdmanurung/ggann/security/advisories/new)
and include a minimal reproduction, affected versions, and impact assessment.

Reports that concern AnnData file parsing or an optional plotting backend may
need coordinated disclosure with the relevant upstream project. No credentials
or private datasets should be attached to a report.
